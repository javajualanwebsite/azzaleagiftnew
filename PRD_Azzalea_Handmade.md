# Product Requirement Document (PRD)
**Project Name:** Website Katalog & Order Inquiry Azzalea Handmade
**Version:** 1.0
**Target Platform:** Web (Mobile-First)

## 1. Project Overview
Azzalea Handmade membutuhkan website berkelas, profesional, dan bernuansa *warm floral* untuk memamerkan katalog souvenir pernikahan. Tujuan utama website ini adalah meningkatkan kepercayaan calon pembeli dan mempermudah konversi pemesanan yang diarahkan langsung ke WhatsApp.

## 2. Target Audience
* **End Customer:** Calon pengantin (usia 22–35 tahun) yang mencari souvenir berkualitas dan elegan.
* **B2B:** Wedding Planner / Event Organizer.

## 3. Design & Branding Guidelines (Berdasarkan Logo)
* **Primary Color (CTA & Highlights):** Coral Rose (`#D85C70`)
* **Background Color:** Soft Cream (`#FAF8F5`)
* **Accent Color:** Soft Teal / Sage (`#3AAFA9`)
* **Text Color:** Charcoal Warm (`#332C27`)
* **Typography:** Modern Sans-Serif (e.g., Poppins / Inter) dipadu dengan script font halus untuk aksen heading.

## 4. Key Pages & Features
### A. Homepage (/)
* **Hero Section:** Headline menarik ("Souvenir Pernikahan Handmade Elegan"), sub-headline, dan CTA "Lihat Katalog".
* **Value Proposition:** 100% Handmade, Custom Design, Harga Bersaing.
* **Best Sellers:** Grid 4-6 produk terlaris.
* **Testimonials:** Carousel foto real-client dan ulasan.

### B. Katalog Produk (/katalog)
* **Product Grid:** Menampilkan foto produk, nama, harga estimasi, dan label kustomisasi.
* **Filter/Kategori:** Pouch, Card Holder, Towel Set, Custom Packaging.

### C. Detail Produk (/katalog/[slug])
* **Galeri Foto:** Resolusi tinggi, multi-angle.
* **Spesifikasi:** Bahan, ukuran, MOQ (Minimum Order Quantity), opsi warna.
* **Estimator Kalkulator:** Input jumlah pcs untuk melihat estimasi harga total.
* **WhatsApp Inquiry Button:** CTA melayang "Pesan via WhatsApp".

### D. Fitur Global
* Floating WhatsApp Button.
* Link Instagram integrasi.
