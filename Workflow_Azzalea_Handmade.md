# System Workflow & User Journey
**Project Name:** Website Katalog & Order Inquiry Azzalea Handmade

## 1. User Journey (Sisi Pembeli)
1. **Discovery:** User masuk ke website lewat Instagram (`@azzaleagiftnew`) atau search engine. Melihat Hero Banner dan terkesan dengan desain *warm floral*.
2. **Exploration:** User scroll ke bagian Best Seller atau masuk ke halaman `/katalog`. User memfilter berdasarkan jenis souvenir (misal: Card Holder).
3. **Detail & Simulation:** User klik salah satu Card Holder. Di halaman detail, user membaca deskripsi, melihat minimum order (MOQ = 100 pcs). User memasukkan angka `250` di kalkulator, dan melihat estimasi total harga.
4. **Action (Inquiry):** User klik tombol "Tanya/Pesan via WhatsApp". Browser otomatis membuka WhatsApp Web/App dengan format teks yang sudah terisi otomatis beserta detail produk dan jumlah pesanan.

## 2. Operational Workflow (Sisi Bisnis - Manual/Internal)
Karena website ini bersifat *Inquiry Gateway*, proses selanjutnya terjadi di luar website:
1. **Lead Verification:** Admin Azzalea (di WhatsApp) menerima pesan. Admin mengonfirmasi ketersediaan stok, waktu produksi, dan slot pesanan.
2. **Design Mockup:** Tim desain Azzalea mengirimkan contoh emboss/sablon nama pengantin ke pelanggan via WhatsApp.
3. **Invoicing & Down Payment (DP):** Jika deal, admin menerbitkan Invoice (PDF/Manual). Pelanggan transfer DP (misal 50%).
4. **Production:** Pesanan diproduksi (handmade).
5. **Quality Control & Full Payment:** Admin mengirim foto produk jadi. Pelanggan melunasi sisa pembayaran + Ongkos Kirim.
6. **Shipping:** Barang dikirim dan resi diberikan ke pelanggan.
